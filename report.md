# Sending a customized gallery email design through the Nitrosend MCP server

- **v0 account:** Sign-up was attempted three times with a fresh email address and was rejected by Vercel each time with a generic error; no verification email ever arrived, so no v0 account exists and the gallery page's "like" and "Open in" steps could not be performed. Fallback used instead: the design was selected from Nitrosend's public gallery catalog and customized through the catalog/API path described below.
- **Nitrosend account:** New — created on 2026-11-05 for this run (free plan). This send was the account's first-ever send through the Nitrosend MCP server.
- **Design picked:** "Field Notes" (gallery id `field_notes`, one of the Nitrosend Originals), taken from the public catalog endpoint that serves the same canonical editor JSON the editor loads for guest editing (`GET /v1/public/templates/field_notes`).
- **Customizations** (made via the API and saved to the account as template id 27026, "China Desk — Field Notes"): all copy rewritten for the sender's own China Desk digest — hero eyebrow and title, intro, both column stories (marketplace fees; KYC timing), closing line, and the button retitled "Read the full digest"; three images swapped (hero: Unsplash `photo-1469854523086-cc02fe5d8800`; columns: `photo-1500530855697-b586d89ba3ee` and `photo-1668952135120-7d997b1b3778`); colours changed — brand colour `#3d5a45` → `#8c2f1b`, text colour → `#201512`, hero/button colour → `#8c2f1b`; the `{{ company.url }}` button href replaced with the project's real page so the design carries no customer-data merge variables (the only remaining `{{ }}` token is `{{ unsubscribe_url }}` in the platform-generated plain-text alternative, which Nitrosend resolves at send time).
- **MCP client used:** Glama MCP Inspector (web client at glama.ai), connected to `https://api.nitrosend.com/mcp` with OAuth sign-in as the account owner; 26 tools were listed. The saved template was confirmed via `nitro_query` (templates) before sending, then `nitro_send_message` sent template 27026 to the proof inbox with subject "China Desk — the rules, in three changes" and a fresh UUID idempotency key. Send result: message id 5380277; read-back status "sent" (sent_at 2026-11-05T18:42:09Z).
- **Receipt:** A signed receipt for the send was published by Nitrosend and emailed to the account owner seconds after the send (receipt email timestamped 2026-11-05T18:42:10Z); the receipt link was opened and verified to resolve before this report was filed.
- **Timing:** 36 minutes from first opening the gallery (2026-11-05T18:06Z) to the receipt (2026-11-05T18:42Z).
- **Slowest step:** The v0/Vercel sign-up — three rejected attempts plus a verification email that never arrived consumed the largest single block of time and ultimately forced the catalog/API fallback for picking up the design.
- **One change I would make to the gallery/editor:** Link each gallery design to its canonical editor JSON (or an "open via API" affordance) from the gallery page itself. The catalog endpoint already serves exactly the JSON the editor loads, but nothing in the gallery UI reveals it; surfacing it would let programmatic users pick up a design without a separate account wall in the way.
